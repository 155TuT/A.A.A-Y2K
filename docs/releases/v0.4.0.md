# A.A.A-Y2K 0.4.0

本版增加原生安装程序，并整理游戏生命周期、地图编辑、输入适配与发布流程。

## 下载

- **Windows x64**：`A.A.A-Y2K-0.4.0-windows-x64-Setup.exe`。提供安装向导、快捷方式、覆盖安装与卸载；无需 Python。它是安装器，安装后部署完整游戏与依赖目录。
- **macOS Apple Silicon**：`A.A.A-Y2K-0.4.0-macos-arm64.pkg`，或同名 `.dmg`。
- **macOS Intel**：`A.A.A-Y2K-0.4.0-macos-x64.pkg`，或同名 `.dmg`。
- **Linux x64**：`A.A.A-Y2K-0.4.0-linux-x64-portable.zip`，完整解压后运行游戏。

PKG 通过系统安装向导安装到 Applications；DMG 提供应用和 Applications 快捷方式。Windows 卸载保留用户存档。各架构独立构建，macOS 包不是 universal2。

## 游戏与实现

- 增加 CRT 外壳、实体音量与彩色/单色控制、圆角窗口及关机动画。
- 保留战役、无尽、五槽存档、地图创作和像素控件。
- 修复重开或替换棋盘时旧局时间被扣入新局的问题；统一新建、重开、续关与读档的计时边界。
- 移除编辑器临时伪造主页状态的处理，明确地图载入与表单回写的顺序。
- 统一生成参数校验，修复畸形设置、布尔数值和超大整数的错误处理。
- 将 Textual 私有接口集中到适配模块，解开窗口宿主与存储结构的依赖；异常退出也释放 SDL 资源。
- 版本号、分辨率和项目地址使用统一来源，并加入静态检查和发布门禁回归测试。

## 验证与文件

GitHub Actions 在 Windows、macOS arm64、macOS x64、Linux x64 四个平台分别运行开发测试、源码与二进制的同一共享套件。安装后再次执行共享套件并验证启动、截图和退出；Windows 还验证重复安装、卸载与用户数据保留。Linux 启动验证使用 Xvfb 虚拟显示。

`*-manifest.json` 记录提交、依赖、源码和资产 SHA-256；`*-verification.zip` 包含开发测试、共享套件、安装运行报告和截图。`SHA256SUMS.txt` 可用于核对下载文件。全部检查通过后，工作流才上传并公开完整 Release。

Windows 安装包未做 Authenticode 签名；macOS 应用使用 ad-hoc 签名，未使用 Developer ID 或 Apple 公证，因此首次安装可能出现系统来源提示。原生 runner 验证不等同于全部系统版本、真实音频硬件或人工游玩的兼容性保证。
