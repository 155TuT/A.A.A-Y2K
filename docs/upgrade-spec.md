# 本轮实现约定

实际工作目录为 A.A.A-Y2K，远端 Git 项目仍为 arrow-Y2K。

- 组合优先、少继承。业务模块通过对象组合协作；仅框架适配保留必要继承。
- 页面分为主页、难度选择、游戏、结算、暂停菜单、设置、五槽存档、成就、地图创作。
- 游戏页只保留棋盘和右侧关卡、生命、LEFT、计时与玩法动作。
- 自动保存默认开启、3 分钟一次；一个自动槽和四个手动槽。快照恢复精确局面，不重新随机生成。
- 所有新游戏从第 1 关编号开始。简单第 3 关后转中等，中等第 10 关后转困难；清除第 3/10/50 关解锁中等/困难/无尽。
- 无尽成功移除增加连击后，奖励 3 + min(7, 连击 // 10) 秒；碰撞断连，不加时间。100 连击或剩余时间超过 15 分钟通关。
- 源码与打包程序均执行相同 selftest 实现，按测试 ID 对比结果；三平台需分别原生构建验证。

规则详见 campaign.md，数据格式详见 storage.md，验证证据详见 verification.md。
