## 自动测试覆盖

- 规则：四向头部射线、空洞、自身阻挡、唯一占格、生命损失、仅同一支回弹箭头忽略重复输入、完整求解证书复放。
- 战役：所有新模式从第 1 关开始；简单第 3 关后转中等、中等第 10 关后转困难；第 50 关完成；新手文案仅用于实际教程。
- 计时：中等 240 秒、困难 120 秒；碰撞中等 −10 秒、困难/无尽 −20 秒，零值失败与生命耗尽优先级；暂停/设置/存档页不扣时间，截止时间优先于下一次点击。无尽从一颗心开始，跨图继承生命并加一、最多三颗；加时、断连、继承时间与两个胜利条件均覆盖。旧存档保留精确时间/生命，新开和重开使用新初始值。
- 并发动画：零间隔连续点击不同箭头立即生效；回弹中同箭头不重复扣血；多颗心独立碎裂；暂停冻结所有时间线；最后一箭/失败等待全部反馈结束后结算。
- 控件：按钮、输入框、开关、选择框共用像素边框，hover 不超出描边且四边内距一致；图标/文字按可见像素居中。各有顶栏页面仅有一个右上角“返回主页”，标题垂直居中；主页与关于页复用官方 GitHub 资源，20×19 采样保留两耳负形；主页 GitHub 在左、退出在右。设置标签和 Switch 悬停/焦点分离，最小化使用淡黄描边与 hover，恢复后清理；快速点击不丢失，Input 仍能编辑。
- 图层：共用套件在两个真实主页按钮的六个鼠标位置触发 Tooltip，检查提示框确实与图标重叠、全框像素正确、中文字形完整。共享套件还验证实际展开选择框的像素边框、绿色高亮与键盘选项；额外回归覆盖下拉菜单遮挡、完整控件边框替换与顶栏按钮点击不触发窗口拖动。
- 启动：源码入口固定调用原生宿主；已移除终端界面分支和 `start.cmd`。传入已删除的 `--terminal` 会在创建玩家数据前被拒绝；源码与二进制执行相同入口测试。
- 保存：死亡、超时、同帧定时保存及立即退出都保留上次活档的原始字节；新局/重开/下一关保存初始活档，关闭开关时不写入；通关快照仍可续关。默认设置、关闭自动保存持久化、保存频率、存活退出保存、一自动/四手动槽、精确局面恢复、先读取自动槽再保存旧局面、损坏存档保留当前游戏。
- 成绩：3/10/50 解锁、箭头和连胜阈值、无尽最快纪录、重复读档不重复结算、未结算快照恢复、演示不计成绩、首次绘制立即记录编辑成就。
- 编辑：预设不可删除、自制地图保存/删除/导入/导出、旧 JSON 兼容、20×16 边界统一、可试玩的边界地图也可以恢复快照。
- CRT：暖白塑料外壳、边缘微弧度和绿光晕；内容与命中位置保持不变，鼠标只换算边框偏移和整数倍率。呈现测试覆盖灯光非同步硬切、扫描线/微噪点、实体键按压、三档图形与输入格点、减少震动模式及关机阶段。电源符号为粗、居中、凿穿透光形式，使用黄色灯光色。共享套件通过实际 SDL 事件验证三档按钮点击、输入框编辑、连续消除两箭、实体键和电源退出；关机只存一次并冻结计时。
- 实体设置：+ / − 连续按每次调整 5 个整数百分点，0–100 限制，无浮点累积误差；实时应用音频并持久化。音频页有效编辑值优先作为起点，无效值回退；只同步主音量数字，不提交其他未保存字段。M 两次恢复原显示模式，新偏好重启后保留，旧设置缺省时默认彩色。写入失败保留磁盘、内存和音频状态；关闭期间均不受理操作。
- 色彩与透明：`palette.py` 的同一语义 token 提供 CSS、Rich 与原生界面颜色；CRT 在内屏完整合成后灰度处理，按钮、输入框、图标、弹层、反光、噪点及 NO SIGNAL 一致变灰，玻璃边沿为灰白，实体灯与机壳保留原色。RGBA 外角透明，区域矩形重建逐像素吻合外壳 mask；Windows 原生 SetWindowRgn 另有真实窗口采样验证。
- 关机：主页 Esc 进入确认页，取消返回；其他页 Esc 仍开菜单。电源、桌面退出、系统关闭共用保存边界，0.30 秒抖闪后显示 NO SIGNAL 1 秒，再结束；真正退出操作幂等。本次真实窗口完成时间为 1.341 秒，0.45 秒时捕获仍存活的 NO SIGNAL 画面。
- 输入取消：实体键按下后移出窗口、窗口失焦、取消外壳拖动时，不会由孤立 MouseUp 再次触发上一次 TUI 按钮；同时覆盖 SDL 同批次排队事件。后续正常点击、快速双击与地图左键绘制/右键擦除仍可用。源码和 EXE 的同一 CRT 用例均重放 M 键取消场景。
- 显示与宿主：三档布局、细箭头旋转一致性、拐角、心碎保留轮廓、结果页红心居中、鼠标坐标、中文输入、分辨率切换、SDL/菜单退出时序。
- 原生宽字符通知：故意让底层按钮的切分边界穿过“百”字，三档分辨率均验证完整字形，未用改变文案绕过。
- 文件和进程边界：原子替换失败保留旧文件；成绩写入失败时提示并保留可玩内存进度，下一次正常写入保存累计值；windowed 的四个空标准流接入日志，测试不污染真实用户日志。

## 复现

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/capture_crt.py --output output/crt-controls-v4
.\.venv\Scripts\python.exe tools/build.py
.\.venv\Scripts\python.exe tools/verify_native.py --output output/native-controls-v4
```

开发测试与构建内嵌测试的范围不同：369 项开发测试包含额外 pytest 回归；其中 33 项共享测试直接从 `selftest.py` 导入，源码 CLI 和最终二进制执行同一份实现。构建必须满足相同用例 ID、全部通过且无跳过，随后才输出 ZIP。详见 [构建说明](build.md)。

页面捕获使用临时隔离数据，难度解锁与成就记录属于测试场景，不能当作真实玩家进度。CRT GIF 使用同一呈现器采样：0.5 秒游玩画面、0.3 秒抖闪、1 秒 NO SIGNAL 与 0.25 秒黑屏，属于视觉回放；实际宿主的延时退出另以真实 SDL 运行验证。静态截图不等同于逐帧人工游玩。窗口拖动测试移动的是真实 SDL 窗口，但鼠标桌面坐标由测试注入；没有执行人工或 OS 鼠标机器人拖动。最小化/恢复通过原生窗口接口执行。恢复后允许真实鼠标产生的新 hover，并校验其命中与全局指针一致；最小化按钮的旧焦点和按下状态必须清空。原生 EXE 启动也使用独立数据目录，测试完成后清理。

## 产物与边界

Windows 目录版：`dist/A.A.A-Y2K/A.A.A-Y2K.exe`，随同目录 `_internal` 一起分发。完整 ZIP：`dist/A.A.A-Y2K-windows-amd64.zip`。构建清单记录源码、字体和其他资源、二进制、ZIP 及测试 ID，可再次计算哈希核对。

本轮保持组合优先：业务状态、独立动画、图标与窗口几何分属现有或新增的单一职责模块，框架适配保留必要的浅继承。此前第 8 张图涉及的地图修改逻辑仍不在本轮改动范围内。

本机实际验证范围为 Windows，已验证原生窗口区域裁切。非 Windows 或不支持区域裁切的后端以机壳暖白色填充桌面窗口角部，导出 RGBA 帧仍保留透明轮廓；该退化路径未进行 macOS/Linux 实机验证。已配置 Windows、macOS、Linux 原生 CI 构建与相同测试门禁；macOS/Linux 尚未在本轮运行，不能把 Windows 成功当作其通过证据。游戏仅提供原生像素窗口，Textual 继续负责布局、组件与交互。尚未在其他应用中验证真实子窗口嵌入，提供的是可复用帧与输入接口。

测试保留 20 条 pygame-ce `Window.from_display_module` 弃用提示，全部来自固定版本的窗口适配调用；当前无失败。升级宿主库时需更新该接口并重跑宿主验证。

CRT 呈现器另做三档彩色/单色各 60 帧的本机基准。先从真实主页取得一次 Textual 合成帧，每种模式预热 8 帧，再单独计时 `CrtShell.render()`；记录包含逐帧数据、输入帧及渲染源码哈希：`output/crt-controls-performance.json`。
