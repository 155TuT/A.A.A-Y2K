## 自动测试覆盖

- 规则：四向头部射线、空洞、自身阻挡、唯一占格、生命损失、仅同一支回弹箭头忽略重复输入、完整求解证书复放。
- 战役：所有新模式从第 1 关开始；简单第 3 关后转中等、中等第 10 关后转困难；第 50 关完成；新手文案仅用于实际教程。
- 计时：中等 240 秒、困难 120 秒；碰撞中等 −10 秒、困难/无尽 −20 秒，零值失败与生命耗尽优先级；暂停/设置/存档页不扣时间，截止时间优先于下一次点击。无尽从一颗心开始，跨图继承生命并加一、最多三颗；加时、断连、继承时间与两个胜利条件均覆盖。旧存档保留精确时间/生命，新开和重开使用新初始值。
- 并发动画：零间隔连续点击不同箭头立即生效；回弹中同箭头不重复扣血；多颗心独立碎裂；暂停冻结所有时间线；最后一箭/失败等待全部反馈结束后结算。
- 控件：按钮不再受默认 0.2 秒按压门限阻塞；设置标签和 Switch 悬停/焦点分离，最小化恢复后清理；真实三连击不选中整页文字，Input 仍能编辑；主页图标与退出按钮样式检查。
- 保存：默认设置、关闭自动保存持久化、保存频率、退出保存、一自动/四手动槽、精确局面恢复、先读取自动槽再保存旧局面、损坏存档保留当前游戏。
- 成绩：3/10/50 解锁、箭头和连胜阈值、无尽最快纪录、重复读档不重复结算、未结算快照恢复、演示不计成绩、首次绘制立即记录编辑成就。
- 编辑：预设不可删除、自制地图保存/删除/导入/导出、旧 JSON 兼容、20×16 边界统一、可试玩的边界地图也可以恢复快照。
- 显示与宿主：三档布局、细箭头旋转一致性、拐角、心碎保留轮廓、结果页红心居中、鼠标坐标、中文输入、分辨率切换、SDL/菜单退出时序。
- 原生宽字符通知：故意让底层按钮的切分边界穿过“百”字，三档分辨率均验证完整字形，未用改变文案绕过。
- 文件和进程边界：原子替换失败保留旧文件；成绩写入失败时提示并保留可玩内存进度，下一次正常写入保存累计值；windowed 的四个空标准流接入日志，测试不污染真实用户日志。

## 复现

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/capture_pages.py --output output/v3
.\.venv\Scripts\python.exe tools/build.py
.\.venv\Scripts\python.exe tools/verify_native.py
```

开发测试与构建内嵌测试的范围不同：266 项开发测试包含额外 pytest 回归；其中 27 项共享测试直接从 `selftest.py` 导入，源码 CLI 和最终二进制执行同一份实现。构建必须满足相同用例 ID、全部通过且无跳过，随后才输出 ZIP。详见 [构建说明](build.md)。

页面捕获使用临时隔离数据，难度解锁与成就记录属于测试场景，不能当作真实玩家进度。动画截图通过注入时钟推进真实控制器取得；静态截图不等同于逐帧人工游玩。窗口拖动测试移动的是真实 SDL 窗口，但鼠标桌面坐标由测试注入；没有执行人工或 OS 鼠标机器人拖动。最小化/恢复通过原生窗口接口执行。原生 EXE 启动也使用独立数据目录，测试完成后清理。

## 产物与边界

Windows 目录版：`dist/A.A.A-Y2K/A.A.A-Y2K.exe`，随同目录 `_internal` 一起分发。完整 ZIP：`dist/A.A.A-Y2K-windows-amd64.zip`。构建清单记录源码、字体和其他资源、二进制、ZIP 及测试 ID，可再次计算哈希核对。

本轮保持组合优先：业务状态、独立动画、图标与窗口几何分属现有或新增的单一职责模块，框架适配保留必要的浅继承。第 8 张图涉及的地图修改逻辑不在本轮改动范围内。

本机实际验证范围为 Windows。已配置 Windows、macOS、Linux 原生 CI 构建与相同测试门禁；macOS/Linux 尚未在本轮运行，不能把 Windows 成功当作其通过证据。终端模式的物理像素依赖终端字体和大小；严格像素效果以默认原生窗口为准。尚未在其他应用中验证真实子窗口嵌入，提供的是可复用帧与输入接口。

测试保留 10 条 pygame-ce `Window.from_display_module` 弃用提示，全部来自固定版本的窗口适配调用；当前无失败。升级宿主库时需更新该接口并重跑宿主验证。
