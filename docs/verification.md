# Demo 验证记录

验证日期：2026-09-21。环境：Windows、Python 3.13.5、Textual 6.12.0、pygame-ce 2.5.8、Pillow 12.3.0。

## 已执行

- `python -m pytest -q`：**78 passed**。包含规则/生成器/存储、像素几何与动画、真实 Textual 控件及原生窗口事件适配。
- `python tools/verify_demo.py`：**210 组**模板/断连地图和种子参数组合，全部成功复放完整零失误通关顺序；保存三关×三尺寸及碰撞、失败、通关、编辑器，共 **13 张**合成截图。
- 实际 SDL 无边框窗口分别启动为 **1024×768、1280×720、1920×1080**，输出 PNG 尺寸与预设一致；另执行宿主分辨率往返、中文输入、粘贴和鼠标消息测试。
- 已逐一目视检查三关、工坊、碰撞碎心、失败与通关状态，修正按钮文字裁切、原生颜色被终端 `NO_COLOR` 环境变量去除、小地图放大尺度不一致的问题。
- 非整数 JSON 坐标（含无限值、布尔值、字符串）在载入边界被拒绝，避免静默截断或未捕获的转换异常。

## 证据位置

`output/verification/report.json` 保存每组生成参数对应的格数/箭头数/证书长度，以及 12 个实现文件的 SHA-256。相邻 PNG 是 Textual 合成帧；`output/window-1024x768.png`、`output/window-1280x720.png`、`output/window-1920x1080.png` 是实际 SDL 显示帧。运行验证脚本可重新生成合成截图与清单。

测试输出包含三次同源弃用警告：pygame-ce 的 `Window.from_display_module` 将来会移除；当前固定版本的窗口操作测试通过。升级 pygame-ce 时需要替换该窗口句柄适配调用并复验，当前没有功能失败。

## 证据边界

自动化动画测试通过推进同一个动画时钟检查完整交互过程及关键路径几何；静态截图不表示逐帧人工游玩测试。普通终端模式的物理像素形状依赖终端字体设置，严格像素显示以默认原生窗口为准。当前验证覆盖 Windows；没有声称在 macOS/Linux 或其他应用的真实子窗口中验证过嵌入。
