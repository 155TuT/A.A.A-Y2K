# Arrow.After.Arrow-Y2K

Python + Textual 的像素点击解谜游戏。Textual 负责页面、组件、输入和时钟；薄 SDL 宿主提供无边框窗口、整数像素显示与三档分辨率。业务以组合为主，规则、存档、成就、音频各有一个负责模块。

## 启动

Windows 双击 `start.cmd`，或在项目目录运行：

```powershell
.\.venv\Scripts\python.exe run.py
.\.venv\Scripts\python.exe run.py --resolution 1024x768
.\.venv\Scripts\python.exe run.py --seed my-seed
```

新电脑需要 Python 3.11+，先运行 `powershell -ExecutionPolicy Bypass -File setup.ps1`。依赖安装到项目虚拟环境。`--terminal` 可在外部终端游玩；精确像素、字体和窗口尺寸以默认桌面模式为准。`--data-dir PATH` 可指定独立数据目录，适合测试或便携部署。

打包版无需 Python：解压完整 ZIP 后运行 `A.A.A-Y2K.exe`，保留旁边的 `_internal` 目录。构建与同源测试见 [打包说明](docs/build.md)。

## 页面与操作

主页提供开始游戏、读取存档、成就、地图创作、设置、退出和 GitHub。新建游戏选择已解锁的起始难度；所有模式均从第 1 关编号开始。

游戏页只显示棋盘与右侧的关卡、难度、生命、LEFT、计时器、提示和局内操作。任意页面按 `Esc` 打开暂停菜单，再按一次返回原页面。菜单包含继续、读取/手动保存、设置、最小化、退出到主页和退出到桌面；暂停期间不计时。

| 操作 | 输入 |
| --- | --- |
| 发射箭头 | 点击箭头身体任意一格，或方向键移动光标后 Enter |
| 提示 / 自动演示 | H / S，演示局不计成就与通关纪录 |
| 重开当前局 | R，恢复同一张棋盘、三颗心和初始时间 |
| 暂停菜单 | Esc |
| 退出 | 菜单退出按钮 / Ctrl+Q |
| 移动无边框窗口 | 在菜单等页面的顶部区域拖动 |

判定从头部下一格沿最后一段方向扫描到棋盘外接矩形边界。空洞不会截断射线，自身身体与其他箭头均会阻挡。畅通时沿原折线路径飞出；碰撞时前冲、震动、变红、退回并损失一颗心。白色心形轮廓保留，粉色内芯碎裂下落。动画期间锁定棋盘点击。

## 难度与进度

| 新建模式 | 关卡进度 | 单张地图初始时间 |
| --- | --- | --- |
| 简单 | 1–3 简单，4–10 中等，11–50 困难 | 简单 XX:XX；中等 10:00；困难 08:00 |
| 中等 | 1–10 中等，11–50 困难 | 10:00 / 08:00 |
| 困难 | 1–50 困难 | 08:00 |
| 无尽 | 持续生成困难地图 | 首张 00:30，此后继承剩余时间 |

通过第 3 / 10 / 50 关分别解锁中等 / 困难 / 无尽。普通模式完成第 50 关即通关。简单前三关固定为小方形、长方形、心形，箭头仍随机生成；首次教程提供对应引导。中等模板为 80–150 格，困难为 150–250 格。

无尽成功移除后增加连击，奖励 `3 + min(7, 连击 // 10)` 秒，最多单箭 +10 秒；碰撞断连且不加时间。100 连击或剩余时间超过 15:00 即通关。清图后继承时间和连击，恢复三颗心。详细规则与快照约定见 [战役说明](docs/campaign.md)。

## 设置、存档与成就

- 基本：自动保存默认开启、默认每 3 分钟，可调整至 1–60 分钟或持久关闭。仅实际游戏时间累计；退出游戏流程前也自动保存，关闭后不再覆写自动槽。
- 音频：静音、总音量、音效音量与试听；使用本地合成音效。
- 画面：1024×768、1280×720、1920×1080；减少震动与闪动。
- 关于：版本、字体许可、数据目录与项目链接。

存档页固定五槽：一个自动槽、四个手动槽。条目显示关号、难度、LEFT、小红心与保存时间。保存精确箭头、生命、计时和连击；读取不会重新生成地图。数据默认位于当前用户的数据目录，Windows 通常为 `%LOCALAPPDATA%/ArrowAfterArrowY2K`，不写入安装目录。

成就覆盖四模式解锁、100/500/1000/100000 支成功移除、10/50/100/500 连续通关、无尽最快用时和地图编辑。新成就在右下角短暂通知。设置和成绩与局面存档分开保存，已结算关卡具有持久标识，反复读档不会重复增加通关记录。见 [存储说明](docs/storage.md)。

## 地图创作

目录展示全部 15 个简单/中等/困难预设。20×16 画布支持左键绘制、右键擦除和按住拖动，方向键与空格也可操作。预设可另存为自己的版本，不能删除。

自制地图可命名、选择难度、保存、删除、导出分享或导入 JSON。配置种子、密度百分比、箭头长度上限与转弯倾向；同一版本下，相同地图和参数生成相同布局。任意空洞和断连形状均支持，试玩前复放生成证书并独立求解确认有解。自制关卡不解锁战役模式。

旧版 `maps/example-heart.json` 仍可导入。空地图、越界格子和无效参数直接提示，保留当前有效数据。

## 像素与模块

格子由 15×15 源像素内部与 1 像素虚线边界组成，格心间距 16。箭头采用统一细线与像素倒角，红心有暗部和微高光；全程禁用抗锯齿。字体为附带许可的 Fusion Pixel 12px 等宽简体中文字库。

| 窗口 | 逻辑帧 | 最终整数倍率 |
| --- | --- | --- |
| 1024×768 | 512×384 | 2× |
| 1280×720 | 640×360 | 2× |
| 1920×1080 | 640×360 | 3× |

棋盘和游戏红心共享绘制倍率，字体所有像素落在同一源像素网格。Textual 固定为 6.12.0，宿主对内部合成器的适配集中在 `desktop.py`。模块职责、求解证明、嵌入接口见 [架构说明](docs/architecture.md)，绘制细节见 [视觉说明](docs/visuals.md)。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe run.py --self-test --test-report build/reports/source.json
.\.venv\Scripts\python.exe tools/verify_demo.py
.\.venv\Scripts\python.exe tools/build.py
```

开发测试覆盖规则、页面消息、计时、五槽保存、解锁、编辑器和像素几何。源码与二进制共同执行 `selftest.py` 中的同一套测试，构建脚本逐项比对测试 ID 和结果。额外的 pytest 回归测试只运行于开发环境，详情及本次实测结果见 [验证记录](docs/verification.md)。

`tools/capture_pages.py` 用隔离测试数据生成三档分辨率的真实 Textual 合成截图与哈希；`--screenshot PATH --quit-after 2` 则记录实际 SDL 显示帧。跨平台工作流在 Windows、macOS、Linux 各自原生 runner 上构建验证；本地实测证据以验证记录为准。
