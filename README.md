# 一箭又一箭 / ARROW AFTER ARROW

Python + Textual 的像素点击解谜 demo。Textual 负责界面组件、布局、焦点、输入、动画时钟和游戏流程；默认通过无边框 SDL 窗口呈现，便于精确控制分辨率。SDL 不提供另一套游戏界面或规则。

## 启动

本目录已建立 `.venv` 并安装依赖。Windows 双击 **`start.cmd`** 即可游玩，也可在项目目录运行：

```powershell
.\.venv\Scripts\python.exe run.py
.\.venv\Scripts\python.exe run.py --resolution 1024x768
.\.venv\Scripts\python.exe run.py --resolution 1920x1080 --level 3
```

换电脑时先安装 Python 3.11 或更高版本，再运行 `powershell -ExecutionPolicy Bypass -File setup.ps1`。依赖只装入项目虚拟环境。`python run.py --terminal` 使用当前终端；终端需要足够的字符行列，字体与窗口装饰由终端控制，不能保证桌面模式的像素精度。

## 玩法和操作

点击箭头占用的任意一格。检测只从头部下一格开始，沿头部最后一段方向延伸到地图的外接矩形边界；空洞没有碰撞体，射线继续穿过。路径上有其他箭头或自身轨迹都会碰撞。每格只能属于一个箭头对象。

- 无遮挡：头部前进，尾部沿旧路径跟随，整支箭头飞出。
- 有遮挡：前冲、撞击抖动、变红、退回；扣一条生命，白色心形轮廓保留，红色内芯碎裂下落并消失。
- 三条生命用尽即失败；清空棋盘即通关。动画期间锁定棋盘点击，防止连点多次扣血。

| 操作 | 鼠标 / 快捷键 |
| --- | --- |
| 选择箭头 | 点击头部或身体；也可方向键移动光标、Enter 发射 |
| 提示 | `H`，标出下一支可以飞出的箭头 |
| 自动演示 / 停止 | `S`，复用正常点击流程逐支播放 |
| 本局重来 | `R` |
| 下一关 | 通关后 `N` |
| 地图工坊 | `E` 或「制作地图」 |
| 返回游戏 | `Esc` |
| 分辨率 | 点击顶部尺寸按钮，或 `F6` 循环切换 |
| 移动窗口 | 拖动左上标题区域 |
| 最小化 / 退出 | 顶部 `_` / `X`；`Ctrl+Q` 退出 |

第一关为 6×6 方形，单格箭头与两支直线箭头引导方向和先后关系。第二关为 9×6 长方形，引入正交折线。第三关为 9×8 心形，含 21 格外侧环绕与 10 格内侧环绕。后续关卡循环菱形、环形、十字和心形模板。`--seed` 决定填充；前三关的引导路径固定。

## 自定义地图

工坊提供六种模板与 12×10 画布：左键绘制、右键擦除，均支持按住拖动；也可用方向键和空格切换格子。断连区域、内部空洞和单独一个格子均可生成。

参数为种子、密度百分比、单支箭头长度上限、转弯倾向百分比。相同地图和参数在锁定的 Python/项目版本下生成相同结果。密度决定实际占用格数；转弯倾向为 0 时只生成直线，较高数值在可选时优先拐弯，但不强制每条路径都拐弯。

「保存」将地图与参数写入路径框指定的 JSON 文件，「载入」恢复两者；「生成并试玩」先构造，再复放验证通关顺序，最后开始游戏。示例在 `maps/example-heart.json`。空地图和无效参数会显示错误并保留当前游戏，不会悄悄换成其他地图。

## 像素显示

格子由 15×15 源像素内部和 1 源像素虚线边界组成，共用边界的格心间距为 16。箭头、网格、红心和字体均用整数坐标绘制，不使用抗锯齿和分数缩放。棋盘与红心共享同一绘制倍率；字体按原生 12px 二值栅格绘制，所有像素落在窗口统一的源像素网格上。

| 窗口 | 逻辑帧 | 最终整数放大 |
| --- | --- | --- |
| 1024×768 | 512×384 | 2× |
| 1280×720 | 640×360 | 2× |
| 1920×1080 | 640×360 | 3× |

棋盘可在逻辑帧内再按整数倍率放大；字体保持原生字号，因此文字的最细笔画可以比放大后的网格线更细，但二者始终对齐同一源像素网格。普通 TUI 中用上下半块字符承载同一像素图；窗口太小时明确提示所需空间，不缩小或裁掉一部分棋盘假装完整显示。

原生启动在 SDL 视频初始化前启用逐显示器 DPI 感知，避免 Windows 对窗口再作位图缩放；这是 SDL 提供的[官方 DPI 配置](https://wiki.libsdl.org/SDL2/SDL_HINT_WINDOWS_DPI_AWARENESS)。

字体为官方 **Fusion Pixel 12px Monospaced / zh_hans**，随项目保留原始字体和许可证。来源与校验见字体目录中的 README；[字体项目](https://github.com/TakWolf/fusion-pixel-font)说明了等宽版的半宽/全宽字符度量。

## 代码结构与验证

具体职责、求解完备性与生成终止性证明、嵌入接口见 [架构说明](docs/architecture.md)。`Textual` 固定为 6.12.0，因为原生窗口桥接使用了框架的内部合成器接口；升级时需要重跑宿主测试。

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\verify_demo.py
.\.venv\Scripts\python.exe run.py --level 3 --screenshot output\heart-window.png --quit-after 2
```

验证脚本输出三关在全部分辨率的界面截图、碰撞/心碎/通关/编辑器状态、同批次测试统计与源码 SHA-256 清单。测试检查真实 Textual 按钮消息与鼠标坐标、三生命失败与重来、完整求解演示、编辑器 JSON 往返，以及生成器证书。截图来自真实 Textual 合成结果；`--screenshot` 则记录实际 SDL 窗口显示帧。

本次执行结果和证据边界见 [验证记录](docs/verification.md)。

当前 demo 不包含账号、云服务、音效、排行榜和关卡解锁存档。地图文件按用户明确点击保存；退出后不会自动保存一局中的中间状态。
