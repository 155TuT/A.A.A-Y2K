# Arrow.After.Arrow-Y2K

Python + Textual 的像素点击解谜游戏。Textual 负责页面、组件、输入和时钟；SDL 宿主提供一个带 CRT 外壳的无边框窗口，内屏采用整数像素显示与三档分辨率。业务以组合为主，规则、存档、成就、音频各有一个负责模块。

## 启动

源码需要 Python 3.11+。在项目目录中安装依赖并启动：

```sh
python -m pip install -e .
python run.py
python run.py --resolution 1024x768
python run.py --seed my-seed
```

建议先用 `python -m venv .venv` 创建虚拟环境。Windows PowerShell 用 `.venv\Scripts\Activate.ps1` 激活，macOS/Linux 用 `source .venv/bin/activate`；随后使用相同的 `python` 命令。Windows 的 `setup.ps1` 可作为安装辅助，游戏统一通过 `run.py` 或打包产物启动。`--data-dir PATH` 可指定独立数据目录，适合测试或便携部署。

安装版无需 Python，从 [GitHub Releases](https://github.com/155TuT/A.A.A-Y2K/releases/latest) 下载对应平台：

| 平台 | 下载与安装 |
| --- | --- |
| Windows x64 | `windows-x64-Setup.exe`：安装向导，支持快捷方式、覆盖安装和卸载 |
| macOS Apple Silicon | `macos-arm64.pkg` 安装向导，或 `.dmg` 拖入 Applications |
| macOS Intel | `macos-x64.pkg` 安装向导，或 `.dmg` 拖入 Applications |
| Linux x64 | `linux-x64-portable.zip`：完整解压后运行其中的 `A.A.A-Y2K` |

Windows 的 Setup EXE 是安装程序；游戏运行文件与依赖由安装器一起部署。用户数据独立于安装目录，卸载 Windows 应用保留存档。0.4.0 的 Windows 包未做 Authenticode 签名，macOS 应用仅有 ad-hoc 签名、未做 Apple 公证。构建、系统提示和验证边界见 [打包说明](docs/build.md)。

## 页面与操作

主页提供开始游戏、读取存档、成就、地图创作、设置、退出和 GitHub。开始/读取一行与后续按钮保持左右对齐，配有播放、文件夹、奖杯、地图和齿轮像素图标；底部左侧为 GitHub 按钮，右侧为红色方形退出按钮。GitHub 按钮与设置“关于”共用官方 Invertocat 图标；图标与文字整体居中，悬停提示按层级完整显示。署名为 `Made By 155TuT with GPT and ♥ Love`，爱心复用游戏生命值绘制。新建游戏选择已解锁的起始难度；所有模式均从第 1 关编号开始。

游戏页只显示棋盘与右侧的关卡、难度、生命、LEFT、计时器、提示和局内操作。主页按 `Esc` 打开“确认要退出吗？”页面，取消或再次按 `Esc` 回主页，确认后退出。其他页面按 `Esc` 打开暂停菜单，再按一次返回原页面。菜单包含继续、读取/手动保存、设置、黄色最小化按钮和退出到桌面；暂停期间不计时。有存活局面时“继续游戏”直接回到游戏。主页及游戏页以外的页面共用顶栏：左侧标题垂直居中，右上角为紧凑的“返回主页”按钮；返回主页保留当前局面。

| 操作 | 输入 |
| --- | --- |
| 发射箭头 | 点击箭头身体任意一格，或方向键移动光标后 Enter |
| 提示 / 自动演示 | H / S，演示局不计成就与通关纪录 |
| 重开当前局 | R，恢复同一张棋盘和初始时间；普通三颗心、无尽一颗心 |
| 暂停 / 退出确认 | 游戏及其他功能页按 Esc 暂停；主页按 Esc 确认退出 |
| 主音量 | 外壳 + / − 键，每次调整 5 个百分点，范围 0–100% |
| 彩色 / 单色 | 外壳 M 键，切换并保存显示偏好 |
| 退出 | 退出到桌面按钮 / Ctrl+Q / 外壳电源按钮 |
| 移动无边框窗口 | 拖动 CRT 外壳或内屏顶栏空白、标题；控件仍响应点击 |

判定从头部下一格沿最后一段方向扫描到棋盘外接矩形边界。空洞不会截断射线，自身身体与其他箭头均会阻挡。畅通时沿原折线路径飞出；碰撞时前冲、震动、变红、退回并损失一颗心。白色心形轮廓保留，粉色内芯碎裂下落。每支箭头独立播放动画，可在一支箭头移动时立即点击其他箭头。同一支正在回弹的箭头不会重复扣血；规则立即结算，结果页等该次反馈结束后展示。连点棋盘或侧栏不会选中整页文字，输入框仍可正常编辑。

CRT 外壳与内屏在同一个窗口中呈现，带轻微扫描线、微噪点，以及边缘的小幅弧度和透绿色光晕；棋盘、文字与按钮的位置保持不变。外壳电源按钮采用居中的粗凿穿符号，透出黄色灯光。+ / − 键实时调整主音量，M 键切换内屏灰度；玻璃边沿随之变为灰白，机壳和实体指示灯保留原色。音量与显示模式在下次启动时保留。退出先结算并保存一次存活局面，随后冻结游戏，播放约 0.3 秒抖闪与 1 秒 `NO SIGNAL`，结束后关闭窗口。“减少震动与闪动”会关闭关机抖闪和动态噪点。

CRT 输出保留透明圆角；Windows 原生窗口同步按外壳轮廓裁切，桌面可以从圆角外露出。其他不支持原生裁切的后端用机壳暖白色填充角部。窗口启动和切换分辨率时按整个 CRT 窗口尺寸及当前显示器可用区域重新定位，支持负坐标的多显示器布局。比屏幕可用区域更大的预设保持原像素尺寸，顶部拖动区域锚定在可见位置；可拖动窗口或切换更小分辨率。最小化、恢复、失焦和切页会清除旧的鼠标悬停与按压状态。

## 难度与进度

| 新建模式 | 关卡进度 | 单张地图初始时间 |
| --- | --- | --- |
| 简单 | 1–3 简单，4–10 中等，11–50 困难 | 简单 XX:XX；中等 04:00；困难 02:00 |
| 中等 | 1–10 中等，11–50 困难 | 04:00 / 02:00 |
| 困难 | 1–50 困难 | 02:00 |
| 无尽 | 持续生成困难地图 | 首张 00:30，此后继承剩余时间 |

通过第 3 / 10 / 50 关分别解锁中等 / 困难 / 无尽。普通模式完成第 50 关即通关。简单前三关固定为小方形、长方形、心形，箭头仍随机生成；首次教程提供对应引导。中等模板为 80–150 格，困难为 150–250 格。

碰撞扣一颗心，同时按当前难度扣时：中等 −10 秒、困难/无尽 −20 秒；简单不扣时间。剩余时间最低为 0，归零失败；同次碰撞同时耗尽生命与时间时，以生命耗尽结算。

无尽从一颗心和 00:30 开始。成功移除后增加连击，奖励 `3 + min(7, 连击 // 10)` 秒，最多单箭 +10 秒；碰撞断连且不加时间。100 连击或剩余时间超过 15:00 即通关。清图后继承时间和连击，生命继承当前值再加一颗，最多三颗。详细规则与快照约定见 [战役说明](docs/campaign.md)。

## 设置、存档与成就

- 基本：自动保存默认开启、默认每 3 分钟，可调整至 1–60 分钟或持久关闭。仅实际游戏时间累计；新局、重开和下一关先保存初始活局，退出游戏流程前保存当前存活局面。死亡或超时保留上次自动档，关闭后所有自动保存时机均停写。
- 音频：静音、总音量、音效音量与试听；使用本地合成音效。实体 + / − 键同步主音量数字；编辑框中有有效数字时从该值开始调整，只保存主音量，保留其他未提交的表单修改。
- 画面：1024×768、1280×720、1920×1080；减少震动与闪动。实体 M 键的单色偏好独立持久化，默认彩色。
- 关于：版本、字体许可、数据目录与项目链接。

存档页固定五槽：一个自动槽、四个手动槽。条目显示关号、难度、LEFT、小红心与保存时间。保存精确箭头、生命、计时和连击；读取不会重新生成地图。已有存档保留原来的精确时间与生命；当前初始值用于新建、下一关和重开，读取后发生的碰撞按当前规则扣时。通关快照可保留续关进度；手动槽仍按玩家操作保存。数据默认位于当前用户的数据目录，Windows 通常为 `%LOCALAPPDATA%/ArrowAfterArrowY2K`，不写入安装目录。

成就覆盖四模式解锁、100/500/1000/100000 支成功移除、10/50/100/500 连续通关、无尽最快用时和地图编辑。新成就在右下角短暂通知。设置和成绩与局面存档分开保存，已结算关卡具有持久标识，反复读档不会重复增加通关记录。见 [存储说明](docs/storage.md)。

## 地图创作

目录展示全部 15 个简单/中等/困难预设。20×16 画布支持左键绘制、右键擦除和按住拖动，方向键与空格也可操作。预设可另存为自己的版本，不能删除。

自制地图可命名、选择难度、保存、删除、导出分享或导入 JSON。配置种子、密度百分比、箭头长度上限与转弯倾向；同一版本下，相同地图和参数生成相同布局。任意空洞和断连形状均支持，试玩前复放生成证书并独立求解确认有解。自制关卡不解锁战役模式。

旧版 `maps/example-heart.json` 仍可导入。空地图、越界格子和无效参数直接提示，保留当前有效数据。

## 像素与模块

格子由 15×15 源像素内部与 1 像素虚线边界组成，格心间距 16。箭头采用统一细线与像素倒角，红心有暗部和微高光；游戏素材使用清晰的整数像素边缘。字体为附带许可的 Fusion Pixel 12px 等宽简体中文字库。菜单像素图标使用有限的阴影和高光；GitHub 使用附带来源说明的官方资源并采样到整数像素网格。按钮及表单控件共用像素边框，悬停填充与四侧描边等距，图标按可见内容居中。退出按钮在各页共享红色描边，Select 的展开标记为三个小圆点。设置标签用描边标明当前页，鼠标悬停与键盘焦点分别呈现，Switch 使用完整的绿色系轮廓。

| 内屏分辨率 | 逻辑帧 | 整数倍率 | 含 CRT 外壳的窗口 |
| --- | --- | --- | --- |
| 1024×768 | 512×384 | 2× | 1104×916 |
| 1280×720 | 640×360 | 2× | 1360×868 |
| 1920×1080 | 640×360 | 3× | 2040×1302 |

界面语义颜色由 `palette.py` 统一提供给 Textual CSS 和原生绘制。单色模式在完整内屏合成后统一过滤，因此按钮、输入框、图标与弹层一起变为灰度。棋盘和游戏红心共享绘制倍率，字体所有像素落在同一源像素网格。Textual 固定为 6.12.0，宿主对内部合成器的适配集中在 `desktop.py`。模块职责、求解证明、嵌入接口见 [架构说明](docs/architecture.md)，绘制细节见 [视觉说明](docs/visuals.md)。

## 验证

```sh
python -m pip install -e ".[dev,build]"
python -m pytest -q
python run.py --self-test --test-report build/reports/source.json
python tools/verify_demo.py
python tools/build.py
```

开发测试覆盖规则、页面消息、计时与碰撞扣时、无尽生命继承、多箭头及多颗心并行动画、窗口拖动定位、控件焦点和选择、顶栏与悬停层级、实体按键与偏好持久化、原生窗口轮廓、死亡后活档保护、五槽保存、解锁、编辑器和像素几何。源码与二进制共同执行 `selftest.py` 中的同一套测试，构建脚本逐项比对测试 ID 和结果。额外的 pytest 回归测试只运行于开发环境，详情及本次实测结果见 [验证记录](docs/verification.md)。

`tools/capture_pages.py` 用隔离测试数据生成三档分辨率的真实 Textual 合成截图与哈希；`--screenshot PATH --quit-after 2` 则记录包含外壳的实际 SDL 显示帧。跨平台工作流在 Windows、macOS、Linux 各自原生 runner 上构建验证；本地实测证据以验证记录为准。
