# Fusion Pixel 12px monospaced

Unmodified `fusion-pixel-12px-monospaced-zh_hans.ttf` from the official
[Fusion Pixel Font 2026.09.01 release](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01),
archive `fusion-pixel-font-12px-monospaced-ttf-v2026.09.01.zip`.

The font is distributed under SIL Open Font License 1.1 (`OFL.txt`). Upstream
notices are retained as `ARKPIXEL-OFL.txt`, `CUBIC11-OFL.txt`, and `LICENSE.txt`
(Galmuri). The source font is rendered at exactly 12 px without antialiasing:
ASCII advances 6 px; CJK advances 12 px. Its pixels and all game art pixels are
enlarged together using nearest-neighbor integer scaling.

Font SHA-256: `b556cf8c588f1fbd237f7f44af142781d50f7dba6d82ae57eae16c154cde2ae9`.
