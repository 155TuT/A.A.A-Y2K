# GitHub project-link icon

The white Invertocat PNG and SVG are unmodified official assets downloaded on 2026-09-22 from [GitHub Brand Toolkit](https://brand.github.com/foundations/logo), [official logo archive](https://brand.github.com/GitHub_Logos.zip).

Original archive entries: `GitHub Logos/PNG/GitHub_Invertocat_White.png` and `GitHub Logos/SVG/GitHub_Invertocat_White.svg`.

Used only as a button linking to the project on GitHub. GitHub and the Invertocat design are trademarks of GitHub, Inc. The source assets retain their original dimensions and colors; the game samples the official PNG onto its integer pixel grid for display. No hand-drawn substitute is used.
